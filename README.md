# Dialogue Archive Ops

This repository holds the legacy conversation archives for the dialogue
platform's tool-using agents.

Repository conventions:

- `main` contains shared documentation, the implementation tracker and the
  team roster.
- Every developer works on their own branch (`dev/<handle>`) and keeps their
  task folders under `tasks/<handle>/<task>/`.
- The implementation tracker (`tracker/implementation_tracker.csv`) records the
  state of every task in the current cycle and who implemented it.
- The team roster (`team/roster.json`) maps each person to their branch and
  personal task root.
